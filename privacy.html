Consulting OS Dashboard - Privacy Policy

Last updated: October 17, 2026

Who we are. Consulting OS Dashboard is a private tool operated by Silicon Valley Insights Group LLC (SVIG) for the sole use of its owner.

What data we access. With the owner's permission, the app reads Google Calendar data (event times, titles and free/busy status) using the read-only scope https://www.googleapis.com/auth/calendar.readonly.

How we use it. Calendar data is used only to show the owner his upcoming meetings and to suggest open time slots for his own client calls.

Storage. Data is stored only on the owner's own computer. It is not uploaded to any server operated by SVIG, not sold, not shared with third parties, and not used for advertising.

Retention and deletion. Locally stored calendar data is refreshed on each use and can be deleted at any time. Access can be revoked at any time at https://myaccount.google.com/permissions.

Google API Services User Data Policy. The app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
